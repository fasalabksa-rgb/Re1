برنامج التكلفة للمحاسبة والمخزون

المستخدم الحالي: أحمد (كاشير) | الوردية: صباحية

إدارات النظام

💼 المبيعات والعملاء
  • 📊 لوحة تحكم المبيعات
  • ➕ إنشاء فاتورة مبيعات (معرف/باركود)
  • 🧾 استعراض الفواتير (المرحّلة والمعلقة)
  • 📄 إنشاء واستعراض عروض الأسعار
  • ↩️ إنشاء فاتورة مرتجع مبيعات
  • 📋 استعراض فواتير المرتجعات
  • 👥 دليل العملاء ومديونياتهم
  • 👤 إضافة عميل جديد
🛒 المشتريات والموردين
  • 📥 تسجيل فاتورة مشتريات جديدة
  • 📦 استعراض فواتير الشراء
  • 🔄 إنشاء مرتجع مشتريات
  • 📋 استعراض مرتجعات المشتريات
  • 🤝 دليل الموردين ومديونياتهم
  • ➕ إضافة مورد جديد
📦 الفروع والمستودعات والمخزون
  • 🔍 استعراض الأصناف ووحداتها
  • ➕ إضافة صنف جديد
  • 🏢 استعراض الفروع والمستودعات
  • ➕ إضافة فرع / مستودع جديد
  • 🚚 إنشاء فاتورة تحويل بين المستودعات
  • 📜 استعراض فواتير التحويل المخزني
  • 📋 طلب جرد مخزني وتسوية الكميات
  • 💲 تعديل تكلفة المخزون
💰 إدارة المالية والنقدية
  • 🏦 استعراض البنوك والصناديق والأرصدة
  • ➕ إضافة بنك / صندوق جديد
  • 💵 إنشاء سند قبض مالي
  • 💸 إنشاء سند صرف مالي
  • 🔄 طلب صرف عُهدة مؤقتة
  • ⚖️ التسويات البنكية ومطابقة الحسابات
🌳 الحسابات العامة
  • 🌿 شجرة الحسابات (الدليل المحاسبي)
  • ➕ إنشاء حساب مالي جديد
  • 📝 إنشاء قيد يومي يدوي
  • 📖 استعراض القيود اليومية ودفتر الأستاذ
  • 🎯 مراكز التكلفة وتحليلها
  • 📉 إدارة الأصول والإهلاكات
  • 💵 الأرصدة الافتتاحية للنظام
  • 🔒 إغلاق الفترة المالية والسنة المحاسبية
👥 الموارد البشرية والأمان
  • 👤 دليل الموظفين وبياناتهم
  • 🔒 إدارة أدوار وصلاحيات الموظفين
  • 🕵️‍♂️ سجل أحداث وتحركات الموظفين (Audit Log)
📊 التقارير والتحليلات
  • 📈 تقارير المبيعات والعملاء
  • 📉 تقارير المشتريات والموردين
  • 📦 تقارير المخزون وحركة الأصناف
  • 🏛️ تقارير الحسابات الختامية والميزانية
📄 القوالب والأتمتة
  • 🖨️ قوالب الطباعة والفواتير الجاهزة
  • 📧 قوالب البريد الإلكتروني والإشعارات
  • 🤖 قواعد الإرسال والربط الآلي
  • ⚖️ الشروط والأحكام والسياسات
  • 📂 إدارة الملفات والمستندات المرفوعة
⚙️ إعدادات النظام
  • ℹ️ معلومات الحساب وبيانات المنشأة
  • 🎨 تخصيص شعار وألوان النظام
  • 🛠️ إعدادات الضرائب والفوترة الإلكترونية (ZATCA)
  • 🔢 إعدادات الترقيم المتسلسل التلقائي
  • 💳 تهيئة طرق الدفع والـ SMTP البريدي
